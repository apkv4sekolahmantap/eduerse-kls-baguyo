# EduVerse Kelas Baguyo — Frontend

Platform game edukasi 3D + asesmen (latihan harian, STS, SAS). Frontend statis (HTML/CSS/JS murni) yang berjalan di **GitHub Pages**; data & logika ada di **Google Apps Script** (REST API JSON).

```
index.html        ← halaman utama (harus di root repo)
css/style.css
js/config.js      ← SATU-SATUNYA berkas yang perlu diedit: isi GAS_URL
js/core.js  js/world.js  js/student.js  js/teacher.js  js/app.js
```

Cara pasang lengkap: lihat `PANDUAN-INSTALASI.md`.
